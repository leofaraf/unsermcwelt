НАШ МАЛЕНЬКИЙ МИР — GITHUB PAGES

Все файлы находятся в корне. Сборка и npm не нужны.

1. Загрузите содержимое этой папки в корень репозитория GitHub.
   Не загружайте весь рабочий каталог Codex: здесь только готовый сайт.
2. Settings → Pages → Deploy from a branch → main → / (root) → Save.
3. Откройте выданный GitHub адрес. Нажмите «Войти в мир»:
   Haggstrom запускается в фоне и повторяется. Видимого плеера нет.
   Кнопка звука или M выключает музыку. До первого нажатия звук не запускается.

СКАЧИВАНИЕ СЕРВЕРА
Создайте обычный опубликованный Release в том же репозитории (не prerelease).
Прикрепите файл minecraft-server-1.21.8-2026-11-06.zip из прежней папки
minecraft-browser/downloads. Он весит 246 МБ и не входит в файлы сайта.
Кнопка автоматически использует latest Release на стандартном домене github.io.
Для собственного домена или другого репозитория вставьте прямую ссылку на файл
Release в releaseAssetUrl в config.js.
Пока Release с файлом не загружен, скачивание на опубликованном сайте не работает.
Архив содержит весь мир, данные игроков и настройки; доступ к нему определяется
доступом к Release. Сайт сам не создаёт Release и не публикует архив.

ЛОКАЛЬНЫЙ ЗАПУСК
В Терминале перейдите в эту папку и выполните:
python3 -m http.server 8003 --bind 127.0.0.1
Откройте http://localhost:8003. Двойной клик по HTML не поддерживается.
